# Security Policy

## Reporting a vulnerability

If you discover a security issue in GameArt Manager, please report it
privately — do **not** open a public issue:

1. Use GitHub's private vulnerability reporting: **Security** tab →
   *Report a vulnerability*.
2. If that is unavailable, contact the repository owner directly via the
   contact listed in [PRIVACY.md](PRIVACY.md).

Include reproduction steps and, where relevant, your Windows version and
whether the app was sideloaded or Store-installed. You should get a
response within a few days.

## Scope

- In scope: this repository's application code, packaging scripts and CI
  configuration.
- Out of scope: SteamGridDB's service, artwork content itself, Xbox app
  behavior, and issues that require an already-compromised machine.

## Handling

Reports are triaged privately, fixed in a patch release, and credited in
the release notes if you wish.
